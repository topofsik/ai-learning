# 과제 제출 기록

회원이 자신의 이름과 제출 날짜, 결과물 링크를 입력해 매일 과제 제출 이력을 남기는 정적 웹앱입니다.

## 기능

- 제공된 25명 회원 명단 기본 탑재
- 회원 이름·날짜·결과물 링크·메모 제출
- 같은 회원이 같은 날짜에 다시 제출하면 기존 링크 갱신
- 날짜별 제출률, 제출/미제출 현황, 미제출자 복사
- 전체 제출 기록 CSV 내려받기
- 회원 명단 CSV 가져오기/내보내기
- `localStorage`를 이용한 브라우저 내 저장

## 실행

ES 모듈을 사용하므로 로컬 웹 서버에서 실행합니다.

```bash
python -m http.server 8000
```

`http://localhost:8000`을 열면 됩니다. 공개 배포본은 [GitHub Pages](https://topofsik.github.io/ai-learning/)에서 확인할 수 있습니다.

## 저장 범위

현재 버전은 별도 서버 없이 브라우저의 `localStorage`에 기록합니다. 따라서 같은 브라우저에서는 기록이 유지되지만, 여러 회원의 기기에서 제출한 기록을 하나의 공용 목록으로 모으려면 Supabase, Firebase 같은 공유 데이터베이스 연결이 추가로 필요합니다.
