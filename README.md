# 카톡 과제 제출 체크

카카오톡 대화 내보내기 파일을 브라우저에서 분석해 멤버별 과제 제출 현황을 정리하는 정적 웹앱입니다.

## 주요 기능

- Android, iOS, PC 카카오톡 내보내기 형식 지원
- `.txt` 파일 선택, 드래그앤드롭, 텍스트 붙여넣기
- 멤버와 여러 카톡 별칭 관리 (`localStorage` 저장)
- 일별 제출 현황, 최초 제출 시각 및 근거 메시지 표시
- 미제출자 명단 복사 및 CSV 내려받기
- 기간별 누적 제출 횟수와 개근 여부
- 브라우저 내 파서 자체 테스트

## 실행

ES 모듈을 사용하므로 로컬 웹 서버에서 실행하는 것을 권장합니다.

```bash
python -m http.server 8000
```

그런 다음 `http://localhost:8000`을 엽니다. GitHub Pages에 배포하면 별도 설치 없이 사용할 수 있습니다.

## 테스트

Node.js가 설치되어 있다면 다음 명령으로 파서 테스트를 실행할 수 있습니다.

```bash
npm test
```

대화 내용과 멤버 정보는 외부 서버로 전송되지 않으며 브라우저 안에서 처리됩니다.
