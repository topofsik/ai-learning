# 과제 제출 기록

회원이 자신의 이름과 제출 날짜, 결과물 링크를 입력해 매일 과제 제출 이력을 남기는 정적 웹앱입니다.

## 기능

- 제공된 25명 회원 명단 기본 탑재
- 회원 이름·날짜·결과물 링크·메모 제출
- 같은 회원이 같은 날짜에 다시 제출하면 기존 링크 갱신
- 날짜별 제출률, 제출/미제출 현황, 미제출자 복사
- 전체 제출 기록 CSV 내려받기
- 회원 명단 CSV 가져오기/내보내기
- Supabase 공유 데이터베이스에 회원·제출기록 저장
- 회원은 로그인 없이 전체 과제와 제출물 확인
- 관리자 비밀번호 로그인 후 회원명단·제출기록 관리
- 휴대폰 홈 화면에 앱으로 설치 가능(PWA)

## 공유 저장소 설정

1. Supabase 프로젝트의 **SQL Editor**에서 [`supabase-schema.sql`](./supabase-schema.sql) 전체를 붙여넣고 실행합니다.
2. Supabase의 **Authentication → Users**에서 `admin@ai-learning.local` 이메일로 관리자를 추가하고 원하는 비밀번호를 설정합니다. 이메일 자동 확인 옵션이 보이면 켜 주세요.
3. 앱의 **회원 관리** 화면에서 관리자 비밀번호를 입력하면 회원 추가·수정·삭제, CSV 가져오기, 제출기록 삭제가 가능합니다.

회원은 별도 로그인 없이 모든 과제와 제출물을 확인하고 제출할 수 있습니다. `supabase-config.js`의 Publishable key는 브라우저용 공개 키이며, DB 비밀번호와 Secret key는 공개하지 않습니다.

## 실행

ES 모듈을 사용하므로 로컬 웹 서버에서 실행합니다.

```bash
python -m http.server 8000
```

`http://localhost:8000`을 열면 됩니다. 공개 배포본은 [GitHub Pages](https://topofsik.github.io/ai-learning/)에서 확인할 수 있습니다.

휴대폰에서는 공개 배포본을 연 뒤 Android Chrome의 **홈 화면에 추가** 또는 iPhone Safari의 **공유 → 홈 화면에 추가**를 선택하면 앱처럼 사용할 수 있습니다.

## 저장 범위

회원과 제출기록은 Supabase에 저장되므로 여러 회원의 기기에서 같은 목록을 확인할 수 있습니다. Supabase 연결이 되지 않는 경우 기존 브라우저의 `localStorage` 기록을 임시로 표시합니다.
